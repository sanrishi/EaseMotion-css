display: contents Layout

Remove wrapper divs from layout while keeping them in the accessibility tree.

Without display: contents

The <li> wrappers break the grid — articles are nested inside list items.

  • Semantic HTML

    Proper heading hierarchy and landmarks.

  • Accessibility Tree

    Screen readers see the <li> items.

  • Grid Layout

    But the grid columns don't behave as expected.

  • Nested Structure

    The <li> creates an extra box in the grid.

With display: contents

The <li> wrappers vanish from layout — articles become direct grid children.

  • Semantic HTML

    Proper heading hierarchy and landmarks.

  • Accessibility Tree

    Screen readers still see the <li> items.

  • Grid Layout

    Articles now flow directly in the grid as intended.

  • Flat Visual Tree

    Wrappers removed from render tree — no extra boxes.

How it works

display: contents causes an element's children to appear as if they were direct children of the element's parent — the element itself generates no box. However, it still exists in the accessibility tree, so screen readers and other assistive technology can still navigate it.

Open DevTools and inspect the list items to see the difference.

Browser support: Chrome 65+, Firefox 60+, Safari 11.1+. display: contents is well-supported across all modern browsers.
